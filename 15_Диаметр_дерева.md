# 15. Диаметр дерева

## Введение

Диаметр дерева - это длина самого длинного простого пути между двумя вершинами дерева. Такой путь называется диаметральным путем, а его концы - концами диаметра.

В дереве между любыми двумя вершинами существует ровно один простой путь. Благодаря этому диаметр можно найти очень просто: двумя запусками BFS или DFS.

Ключевой факт: алгоритм "2 BFS / 2 DFS" работает так:

1. Запустить BFS/DFS из любой вершины и найти самую дальнюю вершину `a`.
2. Запустить BFS/DFS из `a` и найти самую дальнюю вершину `b`.
3. Расстояние `dist[a][b]` - диаметр дерева.

Иногда формулируют "от листьев": самая дальняя вершина от произвольного старта в дереве будет одним из концов диаметра, часто листом; затем самый дальний от нее лист дает второй конец диаметра.

## Основные определения

Дерево - связный неориентированный граф без циклов.

Для дерева с `V` вершинами:

```text
E = V - 1
```

Расстояние между вершинами:

- в невзвешенном дереве - число ребер на пути;
- во взвешенном дереве - сумма весов ребер на пути.

Диаметр:

```text
diameter = max dist(u, v) по всем u, v in V
```

## Логика алгоритма

Пусть мы стартуем из произвольной вершины `s` и находим самую дальнюю вершину `a`.

Интуитивно `a` лежит на краю дерева. В дереве нет циклов и альтернативных маршрутов, поэтому если бы `a` не была концом какого-нибудь диаметра, можно было бы продлить путь дальше, что противоречит выбору самой дальней вершины.

После этого запускаем обход из `a`. Самая дальняя вершина `b` от `a` образует с `a` самый длинный путь в дереве. Его длина и есть диаметр.

## Алгоритм для невзвешенного дерева

Для невзвешенного дерева удобно использовать BFS, потому что он считает расстояния в количестве ребер.

Псевдокод:

```text
farthest(start):
    dist = array[V] filled with -1
    parent = array[V] filled with -1
    queue.push(start)
    dist[start] = 0

    while queue is not empty:
        v = queue.pop()
        for to in g[v]:
            if dist[to] == -1:
                dist[to] = dist[v] + 1
                parent[to] = v
                queue.push(to)

    return vertex with maximum dist

a = farthest(anyVertex)
b = farthest(a)
diameter = dist[b]
```

Если нужен сам путь диаметра, во втором BFS надо сохранить `parent` и восстановить путь от `b` назад к `a`.

## Алгоритм через DFS

В дереве DFS тоже подходит, потому что между вершинами единственный путь. Можно накапливать глубину или расстояние.

Псевдокод:

```text
dfs(v, parent, distance):
    if distance > bestDistance:
        bestDistance = distance
        bestVertex = v

    for to in g[v]:
        if to != parent:
            dfs(to, v, distance + 1)

bestVertex = any
dfs(start, -1, 0)
a = bestVertex

bestDistance = 0
dfs(a, -1, 0)
b = bestVertex
diameter = bestDistance
```

Для больших деревьев рекурсивный DFS может переполнить стек, поэтому иногда лучше использовать итеративный DFS или BFS.

## Взвешенное дерево

Если ребра имеют веса, BFS по количеству ребер уже не подходит для расстояний. Но так как граф - дерево, можно использовать DFS, суммируя веса, или BFS-очередь без приоритета, потому что альтернативных путей нет.

Для каждого ребра `(v, to, w)`:

```text
dist[to] = dist[v] + w
```

При условии, что веса неотрицательные или вообще любые, в дереве путь между двумя вершинами единственный, поэтому не нужны Дейкстра или Беллман-Форд.

На практике для взвешенного дерева чаще пишут DFS:

```text
dfs(v, parent, distance):
    update best
    for (to, w) in g[v]:
        if to != parent:
            dfs(to, v, distance + w)
```

## Структуры данных

Нужны:

- список смежности `g[v]`;
- массив `dist[v]`;
- массив `parent[v]`, если надо восстановить путь;
- очередь для BFS или стек/рекурсия для DFS;
- переменные `bestVertex` и `bestDistance`.

Для невзвешенного дерева список смежности хранит только соседей. Для взвешенного - пары `(to, weight)`.

## Сложность

Один BFS/DFS проходит по всем вершинам и ребрам:

```text
O(V + E)
```

В дереве `E = V - 1`, значит один обход работает за `O(V)`.

Два обхода:

```text
время: O(V)
память: O(V)
```

Память нужна на список смежности, массивы расстояний/родителей и очередь или стек.

## Ограничения

Алгоритм двух обходов опирается на то, что граф является деревом. В произвольном графе он не всегда находит диаметр.

Если граф несвязный, диаметр всего графа не определен как один путь между любыми вершинами. Можно искать диаметр каждой компоненты отдельно, но это уже не диаметр дерева.

Для рекурсивного DFS есть риск переполнения стека на длинной цепочке.

Если нужно количество вершин на диаметральном пути, а не количество ребер, то для невзвешенного дерева:

```text
verticesOnPath = diameterEdges + 1
```

## Применимость

Диаметр дерева нужен в задачах:

- анализ сетей без циклов;
- поиск самой длинной цепочки зависимостей;
- задачи на центры дерева;
- оценка максимального расстояния в иерархиях;
- динамика на деревьях;
- выбор двух наиболее удаленных объектов в древовидной структуре.

Через диаметр также находят центр дерева: середина диаметрального пути является центром или двумя центрами.

## Примеры

Пусть дерево:

```text
1 - 2 - 3 - 4
    |
    5
```

Список ребер:

```text
(1,2), (2,3), (3,4), (2,5)
```

Первый BFS из `1`:

```text
dist[1] = 0
dist[2] = 1
dist[3] = 2
dist[5] = 2
dist[4] = 3
```

Самая дальняя вершина - `4`. Значит, берем `a = 4`.

Второй BFS из `4`:

```text
dist[4] = 0
dist[3] = 1
dist[2] = 2
dist[1] = 3
dist[5] = 3
```

Самая дальняя вершина - `1` или `5`. Диаметр равен `3`.

Один из диаметральных путей:

```text
4 -> 3 -> 2 -> 1
```

Другой:

```text
4 -> 3 -> 2 -> 5
```

## Альтернативный DP-подход

Диаметр дерева можно найти и динамикой.

Для каждой вершины считаем две максимальные глубины вниз по поддеревьям. Лучший путь, проходящий через вершину, равен сумме двух максимальных глубин. Максимум по всем вершинам - диаметр.

Этот подход удобен, когда дерево уже укоренено и вместе с диаметром нужно считать другие характеристики. Но для простой задачи два BFS/DFS обычно проще и надежнее.

## Типичные ошибки

- Применять алгоритм двух BFS к произвольному графу.
- Забыть, что в дереве `E = V - 1`.
- Путать длину в ребрах и количество вершин на пути.
- Восстанавливать путь по `parent` после первого BFS, хотя нужен `parent` второго BFS.
- Использовать рекурсивный DFS на очень глубоком дереве без учета стека.
- Для взвешенного дерева считать расстояние количеством ребер.
