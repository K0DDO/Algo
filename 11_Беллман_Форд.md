# 11. Алгоритм Беллмана-Форда

## Введение

Алгоритм Беллмана-Форда находит кратчайшие пути от одной стартовой вершины до всех остальных во взвешенном графе. Главное преимущество перед Дейкстрой: Беллман-Форд работает с отрицательными весами ребер.

Кроме того, алгоритм умеет обнаруживать отрицательные циклы, достижимые из стартовой вершины. Если такой цикл существует, кратчайший путь до некоторых вершин может быть не определен: можно проходить по отрицательному циклу много раз и бесконечно уменьшать стоимость пути.

## Основная идея

Алгоритм основан на релаксации ребер.

Релаксация ребра `u -> v` веса `w`:

```text
if dist[u] + w < dist[v]:
    dist[v] = dist[u] + w
```

Если кратчайший путь от источника до вершины `v` не содержит циклов, он содержит не более `|V| - 1` ребер. Поэтому достаточно `|V| - 1` раз пройти по всем ребрам и выполнить релаксации.

Ключевой факт: Беллман-Форд делает `|V| - 1` релаксаций всех ребер, а затем выполняет еще один проход по всем ребрам для проверки отрицательного цикла.

## Логика алгоритма

1. Инициализировать расстояния:
   - `dist[source] = 0`;
   - остальные `dist[v] = INF`.
2. Повторить `|V| - 1` раз:
   - пройти по всем ребрам;
   - для каждого ребра выполнить релаксацию.
3. Еще раз пройти по всем ребрам:
   - если какое-то расстояние все еще можно улучшить, существует достижимый отрицательный цикл.

Почему именно `|V| - 1`: простой путь в графе не может содержать больше `|V| - 1` ребер, иначе какая-то вершина повторится, и появится цикл.

## Псевдокод

```text
dist = array[V] filled with INF
parent = array[V] filled with -1
dist[source] = 0

for i in 1..V-1:
    changed = false

    for (u, v, w) in edges:
        if dist[u] != INF and dist[u] + w < dist[v]:
            dist[v] = dist[u] + w
            parent[v] = u
            changed = true

    if not changed:
        break

hasNegativeCycle = false

for (u, v, w) in edges:
    if dist[u] != INF and dist[u] + w < dist[v]:
        hasNegativeCycle = true
```

Оптимизация `changed` не меняет худшую асимптотику, но часто ускоряет работу на практике.

## Обнаружение отрицательного цикла

После `|V| - 1` проходов все кратчайшие пути без повторения вершин уже найдены. Если на дополнительном проходе можно улучшить расстояние, значит улучшение идет через цикл.

Если этот цикл имеет неотрицательный вес, многократное прохождение по нему не улучшает путь. Значит, возможность дальнейшего улучшения означает отрицательный цикл, достижимый из источника.

Если надо найти сам цикл:

1. Запомнить вершину `x`, расстояние до которой улучшилось на дополнительном проходе.
2. Пройти `V` раз по `parent[x]`, чтобы гарантированно попасть внутрь цикла.
3. Затем идти по `parent`, пока вершина не повторится.

## Структуры данных

Нужны:

- список ребер `edges`, элементы `(u, v, w)`;
- массив расстояний `dist[v]`;
- массив предков `parent[v]` для восстановления путей;
- флаг `changed`;
- при необходимости массив или множество вершин, затронутых отрицательным циклом.

Беллман-Форд удобнее реализовать через список ребер, потому что на каждой итерации нужно пройти по всем ребрам.

## Сложность

Время:

```text
O(V * E)
```

Потому что выполняется до `V - 1` полных проходов по `E` ребрам, плюс один дополнительный проход.

Память:

```text
O(V + E)
```

Если список ребер уже дан, дополнительная память `O(V)` на `dist` и `parent`.

## Ограничения

Беллман-Форд работает с отрицательными весами, но не может выдать конечные корректные кратчайшие расстояния до вершин, на которые влияет достижимый отрицательный цикл.

Алгоритм медленнее Дейкстры на графах с неотрицательными весами.

Нужно аккуратно выбирать `INF`, чтобы не получить переполнение при `dist[u] + w`.

В ориентированном графе ребро `(u, v)` релаксируется только в одну сторону. В неориентированном графе каждое ребро обычно добавляют как две дуги.

## Применимость

Беллман-Форд применяют, когда:

- есть отрицательные веса;
- нужно проверить наличие отрицательного цикла;
- граф не слишком большой;
- требуется простой и надежный алгоритм от одного источника.

Примеры:

- финансовые арбитражные циклы;
- графы с "штрафами" и "бонусами";
- системы разностных ограничений;
- задачи, где важно явно обнаружить отрицательный цикл.

## Примеры

Пусть старт `1`, ребра:

```text
1 -> 2 (4)
1 -> 3 (5)
2 -> 3 (-2)
3 -> 4 (3)
```

Инициализация:

```text
dist[1] = 0
dist[2] = INF
dist[3] = INF
dist[4] = INF
```

После первого прохода:

```text
1 -> 2: dist[2] = 4
1 -> 3: dist[3] = 5
2 -> 3: dist[3] = 2
3 -> 4: dist[4] = 5
```

Итоговые расстояния:

```text
dist[1] = 0
dist[2] = 4
dist[3] = 2
dist[4] = 5
```

Кратчайший путь до `4`:

```text
1 -> 2 -> 3 -> 4
```

Вес:

```text
4 + (-2) + 3 = 5
```

## Типичные ошибки

- Запускать Дейкстру на графе с отрицательными ребрами вместо Беллмана-Форда.
- Делать только один проход по ребрам.
- Забыть дополнительный проход для отрицательного цикла.
- Релаксировать из вершины с `dist[u] = INF`.
- Неправильно обрабатывать неориентированные ребра.
- Считать, что наличие отрицательного ребра само по себе означает отрицательный цикл.
