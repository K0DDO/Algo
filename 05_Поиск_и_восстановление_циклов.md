# Поиск и восстановление всех видов циклов

## Введение / определения с нуля

**Цикл** в графе — замкнутый путь, в котором первая и последняя вершины совпадают, а внутренние вершины (или рёбра — в зависимости от определения) не повторяются в простом цикле.

Различают:

| Вид | Граф | Что ищем |
|---|---|---|
| Простой цикл | неориентированный / ориентированный | замкнутый путь без повторения вершин (кроме начала/конца) |
| Любой цикл (есть/нет) | любой | факт существования |
| Обратный цикл DFS | ориентированный | ребро в серую вершину |
| Отрицательный цикл | взвешенный | цикл с суммой весов \(< 0\) |
| Эйлеров цикл | см. отдельный конспект | проходит каждое ребро ровно раз |
| Гамильтонов цикл | см. отдельный конспект | проходит каждую вершину ровно раз |

В лекции (Теория графов I–II) акцент: **DFS + три цвета** для поиска цикла в ориентированном графе; вопросы «как найти другие циклы / цикл в цикле / все возможные циклы».

## Почему DFS и три цвета

Цвета:

- `white` — не посещали;
- `gray` — вошли, ещё не вышли (вершина в стеке рекурсии / на текущем пути);
- `black` — полностью обработали.

**Ключевой факт (орграф):** если из текущей вершины есть ребро в **серую** вершину, найден цикл: путь от серой до текущей + это ребро.

В **неориентированном** графе ребро к родителю — не цикл. Цикл — ребро к уже посещённой вершине, которая **не** родитель.

## Логика работы: есть ли цикл (орграф)

Из лекции:

```text
// color — изначально white
func dfs(v):
    color[v] = grey
    for u : (v, u) in E:
        if color[u] == white:
            dfs(u)
        if color[u] == grey:
            print("цикл есть")
    color[v] = black
```

Полный обход:

```text
DFS(G):
    for u in V: color[u] = white
    for u in V:
        if color[u] == white:
            Visit(u)
```

### Восстановление одного цикла

Нужны предки и момент обнаружения ребра в серую вершину:

```text
dfs(v):
    color[v] = grey
    for u in adj[v]:
        if color[u] == white:
            parent[u] = v
            dfs(u)
        else if color[u] == grey:
            # цикл: u -> ... -> v -> u
            restore_cycle(v, u)
    color[v] = black

restore_cycle(v, u):
    cycle = [u]
    x = v
    while x != u:
        cycle.push(x)
        x = parent[x]
    cycle.push(u)
    reverse(cycle)   # или оставить как есть — порядок обхода
```

## Неориентированный граф

```text
dfs(v, p):
    color[v] = grey
    for u in adj[v]:
        if u == p: continue
        if color[u] == white:
            parent[u] = v
            dfs(u, v)
        else if color[u] == grey:
            # цикл через ребро v--u
            restore_cycle(v, u)
    color[v] = black
```

Альтернатива без трёх цветов: `visited[]` + родитель; ребро к visited и не родителю = цикл.

## Все виды циклов: классификация рёбер DFS

В ориентированном графе при DFS рёбра делятся на:

1. **Tree edges** — в белую вершину (рёбра дерева DFS).
2. **Back edges** — в серую (образуют циклы).
3. **Forward edges** — в чёрного потомка.
4. **Cross edges** — в чёрную вершину другой ветви.

Каждое **back edge** \((v, u)\) вместе с путём дерева от \(u\) до \(v\) даёт **фундаментальный цикл**.

### Все фундаментальные циклы относительно DFS-дерева

1. Построить DFS-лес.
2. Для каждого обратного ребра восстановить цикл через `parent`.
3. Получим базис циклов (для связного неориентированного графа размер базиса = \(E - V + 1\) — цикломатическое число).

Это отвечает на вопрос лекции «как найти все возможные циклы» в практическом смысле: все циклы — линейные комбинации фундаментальных (в неориентированном случае над \(\mathbb{Z}_2\)).

### «Цикл в цикле» / вложенные циклы

Если нужно перечислить **все простые** циклы (не только фундаментальные):

- алгоритм Джонсона: \(O((V+E)(C+1))\), где \(C\) — число простых циклов;
- бэктрекинг DFS с множеством вершин на текущем пути;
- ограничение: число простых циклов может быть экспоненциальным \(\Rightarrow\) полный перебор дорогой.

Идея бэктрекинга:

```text
dfs(v, start, path, inPath):
    for u in adj[v]:
        if u == start and path.length >= 2:
            report_cycle(path + [start])
        else if not inPath[u] and u >= start:  # эвристика против дублей
            inPath[u] = true
            dfs(u, start, path+[u], inPath)
            inPath[u] = false
```

Для каждой стартовой вершины запускают поиск; дубликаты фильтруют (канонический поворот цикла, направление).

## Отрицательные циклы (взвешенный граф)

### Беллман–Форд

После \(|V|-1\) релаксаций ещё один проход: если ребро ещё релаксируется — вершина достижима из отрицательного цикла. Восстановление: идти по `parent` \(|V|\) раз, затем собрать цикл.

### Флойд–Уоршалл

Изначально \(W[i][i] = 0\). Если после алгоритма \(W[i][i] < 0\), вершина \(i\) лежит на отрицательном цикле (из лекции Теория графов III–IV).

## Структуры данных

| Назначение | Структура |
|---|---|
| Граф | список смежности |
| Состояние | массив цветов `color[V]` |
| Восстановление | `parent[V]`, стек/путь DFS |
| Все простые циклы | множество на пути, список ответа |
| Отрицательный цикл | `dist`, `parent` или матрица \(W\) |

## Сложность

| Задача | Время | Память |
|---|---|---|
| Есть ли цикл | \(O(V+E)\) | \(O(V)\) |
| Один цикл + восстановление | \(O(V+E)\) | \(O(V)\) |
| Все фундаментальные циклы | \(O(V+E + \sum \text{длин})\) | \(O(V+E)\) |
| Все простые циклы | экспоненциально от \(C\) | \(O(V)\) + ответ |
| Отрицательный (BF) | \(O(VE)\) | \(O(V)\) |
| Отрицательный (FW) | \(O(V^3)\) | \(O(V^2)\) |

## Ограничения

- Полный перечень простых циклов на больших графах нереалистичен.
- В неориентированном графе не считать ребро к родителю циклом.
- В орграфе цикл \(\neq\) слабая «петля» через неориентированную проекцию.
- Гамильтонов / Эйлеров — отдельные критерии и алгоритмы.

## Применимость

- проверка ацикличности (DAG) перед топосортировкой;
- обнаружение взаимных блокировок / зависимостей;
- финансовый арбитраж (отрицательный цикл);
- построение базиса циклов в электрических/химических сетях;
- отладка графов зависимостей.

## Пример (орграф)

Вершины \(1 \to 2 \to 3 \to 2\):

1. `dfs(1)`: 1 gray → 2 gray → 3 gray.
2. Из 3 ребро в 2, `color[2]=grey` → цикл \(2 \to 3 \to 2\).
3. Восстановление: `parent[3]=2`, ребро \(3\to2\) → цикл `[2,3,2]`.

## Пример (неориентированный)

Рёбра \(a-b, b-c, c-a\):

- DFS: \(a\) → \(b\) → \(c\), из \(c\) ребро к \(a\) (visited, не родитель \(b\)) → цикл \(a-b-c-a\).

3. Как восстановить цикл по массиву предков?

5. Как найти отрицательный цикл Беллманом–Фордом / Флойдом?
6. Почему «найти все простые циклы» может быть экспоненциально?

## Дополнительно

**Лемма о DFS (из лекции):** нет ребра из чёрной вершины в белую в процессе DFS.

**Лемма о белых путях:** если остановить DFS на серой \(u\) в момент \(T_1\) и дождаться, пока \(u\) станет чёрной (\(T_2\)), то белые вершины либо останутся белыми, либо станут чёрными — причём чёрными станут достижимые от \(u\) по белым путям.

Это обосновывает корректность окраски и детекции обратных рёбер.

### Связь с конденсацией

Если в орграфе есть цикл, все его вершины попадают в одну компоненту сильной связности. Конденсация по SCC всегда является DAG (ациклична).

### Практический чеклист на экзамене

1. Определить: ориентированный / нет, нужен факт или сам цикл.
2. DFS + цвета (или visited + parent).
3. При back edge — восстановить через parent.
4. Если «все циклы» — уточнить: фундаментальные или все простые.
5. Если веса — отдельно про отрицательные циклы.
