# 25. Автомат поиска подстроки

## Идея

Автомат поиска подстроки - это конечный автомат, который читает текст слева направо и после каждого символа хранит состояние: длину наибольшего префикса образца `P`, совпадающего с суффиксом уже прочитанного текста.

Это та же идея, что в КМП, но вместо вычисления откатов на лету мы заранее строим таблицу переходов:

```text
go[state][c] -> next_state
```

Состояние `q` означает:

```text
последние q символов прочитанного текста равны P[0..q-1]
```

Если состояние стало `m = |P|`, значит найдено вхождение образца.

## Связь с префикс-функцией

В КМП при несовпадении мы делаем:

```text
k = pi[k - 1]
```

В автомате этот переход уже заранее посчитан для каждого состояния и символа. Поэтому обработка символа занимает строго `O(1)`.

Состояния:

```text
0, 1, 2, ..., m
```

где `m` - терминальное состояние полного совпадения.

## Построение переходов

Для каждого состояния `q` и символа `c` нужно понять, какой максимальный префикс `P` является суффиксом строки:

```text
P[0..q-1] + c
```

Наивно это можно делать перебором длины ответа. Но эффективнее использовать префикс-функцию и динамику:

```text
if q < m and c == P[q]:
    go[q][c] = q + 1
else:
    if q == 0:
        go[q][c] = 0
    else:
        go[q][c] = go[pi[q - 1]][c]
```

Смысл: если символ не продолжает текущий префикс, мы переходим в состояние, соответствующее лучшему бордеру текущего префикса, и пробуем тот же символ уже оттуда.

## Псевдокод

```text
build_automaton(P, alphabet):
    m = len(P)
    pi = prefix_function(P)
    go = table((m + 1) x |alphabet|)

    for q = 0..m:
        for c in alphabet:
            if q < m and c == P[q]:
                go[q][c] = q + 1
            else:
                if q == 0:
                    go[q][c] = 0
                else:
                    go[q][c] = go[pi[q - 1]][c]

    return go
```

После состояния `m` переходы тоже нужны, чтобы искать перекрывающиеся вхождения. Они строятся по тому же правилу через `pi[m-1]`.

## Поиск

```text
search(T, P):
    go = build_automaton(P, alphabet)
    state = 0
    ans = []

    for i = 0..len(T)-1:
        state = go[state][T[i]]
        if state == len(P):
            ans.push(i - len(P) + 1)

    return ans
```

Если символ текста не входит в заранее заданный алфавит, его нужно обрабатывать как переход в `0` или расширять алфавит.

## Пример

Пусть:

```text
P = abaca
```

Состояния:

```text
0: ничего не совпало
1: совпало "a"
2: совпало "ab"
3: совпало "aba"
4: совпало "abac"
5: совпало "abaca"
```

Если мы в состоянии `3` (`aba`) и приходит `b`, продолжить до `abab` нельзя, потому что `P[3] = c`. Но суффикс `ab` у строки `abab` совпадает с префиксом `P`, поэтому автомат перейдет в состояние `2`, а не в `0`.

Это ровно то, что КМП сделал бы откатами через `pi`.

## Сложность

Построение:

```text
O(m * |A|)
```

где `|A|` - размер алфавита.

Поиск:

```text
O(n)
```

Память:

```text
O(m * |A|)
```

Если алфавит большой, таблица может быть слишком тяжелой.

## Структуры данных

- Массив `pi`.
- Таблица переходов `go`.
- Нумерация символов алфавита.
- Текущее состояние.
- Массив ответов.

Для маленького алфавита удобно хранить `go` как двумерный массив. Для большого алфавита можно хранить словари переходов или вычислять переходы лениво.

## Сравнение с КМП

КМП:

- меньше памяти: `O(m)`;
- переход может выполнять несколько откатов, но суммарно весь поиск `O(n)`;
- проще при большом алфавите.

Автомат:

- больше памяти: `O(m * |A|)`;
- каждый символ обрабатывается строго за `O(1)`;
- удобен, если один и тот же образец используется для большого количества текстов.

## Ограничения

- Автомат строится для одного образца. Для множества образцов нужен Ахо-Корасик.
- Большой алфавит делает таблицу переходов дорогой.
- При изменении образца автомат нужно перестроить.
- Как и КМП, автомат ищет только точные совпадения.

## Применимость

- Быстрый многократный поиск одного шаблона.
- Обработка потоков, когда нужен `O(1)` переход на символ.
- Лексические анализаторы и конечные автоматы.
- Основа для понимания Ахо-Корасика: Ахо-Корасик обобщает автомат КМП на много шаблонов.
